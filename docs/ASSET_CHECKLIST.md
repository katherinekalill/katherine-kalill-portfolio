## Before any file enters the public site

- Record the exact file, dimensions, useful crop/focal point, and intended page placement.
- Verify source/owner, photo/video creator, credit wording, public-site and public-repository scope, and any participant or client restrictions.
- Mark per-file permission approved, pending, or unavailable. Katherine's folder-level authorization is not the same as third-party clearance.
- Confirm informative alt text or explicitly mark the image decorative. Establish a required credit or confirm no credit is required.
- Remove identifying metadata where appropriate; produce optimized local web assets only after the file is cleared.
- Record a derived still's source video in the private ledger and obtain approval of the Goop still-frame selection.
- Keep original source files and evidence links in private storage. Never ship source notes, filenames that expose personal information, or internal evidence references in public manifests.
